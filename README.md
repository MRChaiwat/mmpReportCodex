# MMP Budget Dashboard

Run locally:

```bash
npm.cmd run build
npm.cmd run server
```

Open:

```text
http://localhost:4173
```

Demo users:

```text
admin / admin123
manager / manager123
sales / sales123
```

Only `admin` can upload Excel files. The dashboard updates after each successful upload.
